## Source

The `*.design.md` files in this directory come from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) at commit `fcc70284932276d085f01ef9f83edde90b1258cb`. Each one is the upstream `design-md/<slug>/DESIGN.md`, copied byte for byte and renamed. `SOURCE.json` records the commit, the commit date and a SHA-256 for every file. `scripts/sync-design-systems.mjs` in the finesse repository produces this directory, and rerunning it reproduces it.

## What these files are

Each file is an independent analysis of the publicly visible styling of a website: colours, type, spacing, radius, elevation and component shapes. None of them is an official design system, and none was published or approved by the company it describes. Some files spell a brand name differently on purpose (for example in their front matter). The upstream authors chose those spellings, and finesse keeps them unchanged.

## Removal requests

If you own a brand described here and want its file removed from finesse, open an issue on the finesse repository at https://github.com/Justmalhar/finesse-skill/issues. The file is removed in the next release, and the sync script skips it from then on.
